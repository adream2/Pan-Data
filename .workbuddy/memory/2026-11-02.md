## 做了什么

搭建 TG 公开频道网盘链接采集管线（工作区 E:/WorkBuddy/PANSOU）：

- `collector/fetch_tg.py`：纯标准库（urllib + html.parser）实现，零依赖。
  - 数据源 `t.me/s/<频道>` 网页预览，`?before=<min_post_id>` 分页，约 20 条/页。
  - 自研 `TgChannelParser`：按 div 层级切消息（不依赖 bs4），取正文 + 富文本 `<a href>` + time.datetime。
  - 13 个网盘平台正则；提取码按「同行→下一行→上一行」就近匹配，兼容 `?pwd=`。
  - 标题优先取「名称／标题：」结构化字段，其次首行；额外抽「描述：」存 `desc`。
  - 429/IncompleteRead/SSL EOF 均有指数退避重试。
- `.github/workflows/tg-collect.yml`：cron 每 30 分钟（7,37 分），增量提交 `data/links.jsonl`。
- `tools/make_preview.py`：生成单文件 `preview.html`（搜索 + 平台筛选 + 复制链接），数据内嵌无外部依赖。
- `data/links.jsonl` 为数据存储，`links.jsonl` 一行一条，id = provider + 链接路径 sha1 前 16 位。

## 追加：标题归一化 title_norm.py（抄 tgmonitor core_title 思路，重写为 200 行标准库版）

- `parse_title(raw)` → `core_title / year / season / episode / complete / group_key`
- 规则要点：剥「名称：」「国剧 」「【国漫】」前缀；在「(2025)」「更至23集」「第2季」「4K HDR」
  「类型：」处截断；删尾部平台名/清晰度；清 emoji 与落单括号。
- group_key = sha1(core_title|year|season)，集数不进 key（追更同组）。
- 陷阱记录：`更` 单独做截断词会误伤「更年期」→ 必须要求「更+数字+集/期」。
- 实测 894 条 → 712 组（原粗暴去标点法 752 组），最大组「走马上任」11 个来源跨 4 频道；
  嫁金钗同组内集数 25/26，说明追更聚合生效。
- 预览页每行加了元信息行（年份/季/更新至X集/N 个来源），node --check 校验过 JS 语法。

## 追加：追更收敛 grouping.py（组内选当前版本）

- `grouping.apply(rows)` 给每条打 `group_size / best_episode / group_role / superseded_by`。
- 角色三态：`current`（每组唯一）/ `duplicate`（同集另一来源）/ `superseded`（集数更少）。
- 优先级：链接有效 > 未巡检 > 失效 → 集数大 → 完结 → 发布时间新。
  关键设计：**失效的新集不会盖掉有效的旧集**，避免前端点开死链。
- 采集（fetch_tg）和巡检（check_links）结束都会调用一次重新收敛。
- 实测：894 条 → 698 个资源，重复 179、旧版本 17；最大组「走马上任」14 来源跨 6 频道。
- 踩坑：`group_key` 里带年份会把「吞噬星空(2020)」和「(2025)」拆成两组（搬运年份≠出品年份），
  已改为只含 core_title + season。分组数 712 → 698。
- 预览页把「合并同名资源」改成「只看当前版本」（默认勾选），行内显示「同集重复来源」/
